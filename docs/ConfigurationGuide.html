Hospital Queueing System Configuration Guide

Apps: MultiDepartmentQueueing, HospitalQueueCaller, and HospitalQueueIssuer.

Queue Storage

"QueueStorage": {
  "StateFilePath": "%LOCALAPPDATA%/HospitalQueueingSystem/hospital_queue_state.json"
}

Use the same path in all apps. For LAN deployment, use a shared path like:

"StateFilePath": "//192.168.1.200/HospitalQueueData/hospital_queue_state.json"

Do not store PC credentials in the app. Use Windows sharing permissions or Credential Manager.

Logos

Logo paths are relative to the app folder unless an absolute path is provided.

Departments

{ "Name": "Emergency", "Code": "EMR", "AccentColor": "#DC2626" }

The code controls ticket number format such as EMR-R001 and EMR-P001.

Caller Users

username|password|departmentCode|displayName

Print

"Print": {
  "PrinterMode": "Default",
  "PrinterName": "",
  "TicketTempFolder": "%TEMP%/HospitalQueueTickets",
  "PaperName": "Queue Ticket 58x90mm",
  "PaperWidthHundredthsInch": 228,
  "PaperHeightHundredthsInch": 354
}

The issuer saves each ticket to the temp folder before printing.

Speech

The display uses installed free Windows voices. Placeholders: {Number}, {Counter}, {Department}, {Lane}.

Daily Reset

Numbers reset automatically each day for all departments.
