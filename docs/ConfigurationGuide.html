Hospital Queueing System Configuration Guide

Apps: MultiDepartmentQueueing display/dashboard and HospitalQueueCaller counter app.

Logos and Display Text

Logo paths are relative to each app folder unless an absolute path is provided.

"Logos": {
  "MainLogoPath": "assets/logos/MedixHMSFullLogo.png",
  "SecondaryLogoPath": "assets/logos/SKPH Hospital Logo.png",
  "MultiDepartmentQueueingIconPath": "assets/icons/MultiDepartmentQueueing.png",
  "HospitalQueueCallerIconPath": "assets/icons/MedixHMSIcon.png"
},
"DisplayText": {
  "WindowTitle": "Hospital Queueing Display",
  "HeaderTitle": "Sultan Kudarat Provincial Hospital Queuing System",
  "NowServingTitle": "Now Serving"
}

The caller app uses the Medix HMS logo and HospitalQueueCallerIconPath; its secondary display logo is blank.

Queue Storage

"QueueStorage": {
  "StateFilePath": "%LOCALAPPDATA%/HospitalQueueingSystem/hospital_queue_state.json"
}

Use the same path in all apps. For LAN deployment, use a shared path like:

"StateFilePath": "//192.168.1.200/HospitalQueueData/hospital_queue_state.json"

Do not store PC credentials in the app. Use Windows sharing permissions or Credential Manager.

Speech

Display app speech is enabled; caller app speech is disabled. The display uses installed Windows voices and supports placeholders {Number}, {Counter}, {Department}, and {Lane}.

"VoiceName": "Microsoft David Desktop",
"PronunciationOverrides": {
  "AB": "ey bi",
  "AP": "ey bi"
}

UI Theme

UI.Theme can be Dark or Light. Display defaults to dark mode; caller defaults to light mode.

Daily Reset

Regular and priority numbers reset to 001 each day, and waiting tickets plus recent calls are cleared.

$env:DOTNET_CLI_HOME='C:\Users\Ver\OneDrive\Documents\QueueuingNoIssuer\.dotnet_home'
